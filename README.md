# 🎓 ИИ-ассистент для цифрового кампуса
> Проектная деятельность · Московский Политех · 2026

Интеллектуальный чат-ассистент для первокурсников Московского Политеха. Отвечает на вопросы про стипендии, справки, общежития и учебный процесс **строго по официальным регламентам вуза** со ссылками на источники.

---

## 👥 Распределение команды разработки (8 человек)
> 📋 Полный план проекта, контракты модулей и роадмап: [project-plan.md](project-plan.md)

- **Тимлид (Архитектура и интеграция):** общая координация, Git-flow, код-ревью, интеграция модулей.
- **Модуль 1 (Загрузка данных):** `core/document_loader.py` — парсинг PDF, MD, TXT, нарезка на чанки.
- **Модуль 2 (Индексация и поиск):** `core/retriever.py` — алгоритм поиска BM25, ранжирование фрагментов.
- **Модуль 3 (Интеграция с нейросетью):** `core/llm_client.py` — подключение API (GigaChat / YandexGPT), системные промпты.
- **Модуль 4 (Интерфейс):** `app.py` — веб-чат на Streamlit, отображение цитат, источников и кнопок обратной связи.
- **Модуль 5 (Тестирование и метрики):** `tests/` — проверка качества поиска, сбор тестовых вопросов (30-50 шт.), валидация ответов.

## 🚀 Как запустить проект локально

### 1. Клонировать репозиторий:
```bash
git clone https://github.com/terpeterter/campus-assistant.git
cd campus-assistant
```

### 2. Создать и активировать виртуальное окружение:
**Windows (PowerShell):**
```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Установить зависимости:
```bash
pip install -r requirements.txt
```

### 4. Запустить веб-интерфейс:
```bash
streamlit run app.py
```
После запуска в браузере автоматически откроется страница ассистента (`http://localhost:8501`).

## 🌿 Правила работы с Git (Git-flow)
1. **Никаких прямых коммитов в `main`!**
2. Для каждой задачи создавайте отдельную ветку от `main`:
   ```bash
   git checkout -b feature/название-фичи
   ```
3. Сделайте коммит и отправьте ветку на GitHub:
   ```bash
   git add .
   git commit -m "Понятное описание того, что сделали"
   git push origin feature/название-фичи
   ```
4. Откройте **Pull Request (PR)** в `main` на GitHub и запросите ревью у тимлида.
